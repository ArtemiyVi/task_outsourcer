Это приложение для переноса выполнения ресурсоёмких задач на сервер ЦФ. Создаётся в рамках дипломного проекта для демонстрации идеи приложения и возвожности размещения разработок студентов на сервере ЦФ для последующего использования.

Чтобы начать использовать это приложение вам надо зарегестрироваться в системе. Далее вы сможете перейти в раздел выбора задач, которые вам требуется отправить на выполнение. Заполняете все необходимые параметры и прикрепляете файлы и можете начинать выполнение. После вы можете перейти в личный кабинет и отслеживать состояние выполнения вашей задачи. Выполнение задачи может иметь следующие состояния: CREATED - задача создана и находится в очереди на выполнение, IN_PROCESSING - задача в процессе выполнения, FINISHED - задача успешно выполнилась и вы можете скачать результат её выполнения, ERROR - задача не смогла выполниться по причинам кривости скриптов её запускающих или из-за неправильно заданных значений при её запуске.
